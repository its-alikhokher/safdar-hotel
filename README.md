# Safdar Hotel

Safdar Hotel is a traditional restaurant in Takht Bhai, serving authentic local food and warm hospitality since 1935.

## Our Specialities

- Famous Chapli Kabab
- Mixed BBQ Platter
- Kabuli Mutton Polaw
- Chicken and Mutton Karahi
- Rosh
- Traditional breakfast and chai
